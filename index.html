A股量化选股平台

这是 GitHub Pages 静态入口。完整功能包括沪深全市场抓取、1/5/20日预测、100轮以上优化、逐日误差验证、DeepSeek 复核。

重要说明

GitHub Pages 只能运行静态 HTML/CSS/JS，不能运行 Python、FastAPI、AKShare、Baostock、Tushare，也不能在网页端直接爬取 A 股全市场数据。因此只打开 GitHub 仓库网址或 Pages 静态网址，无法完成完整量化流程。

完整运行方式

在本机、VPS、Render、Railway、云服务器等能运行 Python 的环境执行：

pip install -r requirements.txt
$env:DEEPSEEK_API_KEY="你的DeepSeek Key"
python server.py

然后打开：
